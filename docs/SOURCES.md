Les API publiques ne garantissent pas la pertinence, l’exhaustivité, l’actualité ou la vérité des données pour une question de veille. ClinicalTrials est un registre déclaré, pas un répertoire de médicaments approuvés. Une phase n’est pas une décision réglementaire. Un résumé PubMed peut être protégé : ne pas republier librement des corpus de résumés sans examen des droits.
